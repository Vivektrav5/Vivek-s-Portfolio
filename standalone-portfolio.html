DMI Finance · Enterprise BFSI · Feb 2026 - Present

Automated Financial Compliance & Role-Based Workflows

78% TAT Reduction

The Problem

Critical financial agreements and loan sanction documents required multi-tier compliance reviews across credit, risk, and legal teams. Manual email chains and file shares caused 3 to 5 day review lags, risk of untracked revisions, and compliance audit exposure.

Architecture & Stack

Engineered custom SPFx document viewing components embedded in secure SharePoint Document Sets. Connected to multi-tier Power Automate cloud flows evaluating dynamic Delegation of Authority (DOA) matrices against Dataverse security roles with automated PDF watermarking.

Stack: SPFx, TypeScript, Power Automate, Dataverse, SharePoint REST, PDF Converter

Business Outcome

  • Turnaround time collapsed from 4.5 days to under 18 hours.
  • 100% immutable audit trail for external regulatory inspections.
  • Zero unauthorized document overrides across 400+ monthly files.
BirlaSoft · Enterprise Modernization · Sept 2024 - Jan 2026

Custom SPFx & Power Apps Hybrid Modernization

7 Devs Led · 3.2x Faster Load

The Problem

Enterprise client suffered from legacy AngularJS web applications embedded in older SharePoint tenancies that were sluggish, non-responsive on mobile devices, and incompatible with modern security token protocols. Standard Canvas apps lacked specific UI grid controls needed.

Architecture & Stack

Led an Agile squad of 7 developers building a hybrid architecture: encapsulated React/TypeScript SPFx components embedded into Canvas Power Apps via custom PCF controls, consuming SharePoint Online REST APIs with centralized state management and PnPjs.

Stack: SPFx v1.18, React, TypeScript, PCF, Canvas Power Apps, PnPjs, Azure DevOps

Business Outcome

  • Complete decommissioning of deprecated AngularJS codebase across 12 sites.
  • 3.2x performance acceleration in client data grid rendering.
  • Established reusable PCF component library adopted across enterprise teams.
DMI Finance · Data Engineering & Automation · 2026

Automated Python & M365 REST API Data Pipeline

4 Days → 18 Minutes

The Problem

Every month-end, operations teams received hundreds of loan disbursement spreadsheets uploaded across multiple SharePoint libraries. Manual reconciliation, validation against schema rules, and ingestion into core financial databases took 4 full business days with human error risks.

Architecture & Stack

Designed headless Python ETL microservice authenticating directly via SharePoint Online REST APIs with Azure Key Vault secrets. The pipeline reads streaming Excel bytes with Pandas, runs automated schema verification, flags anomaly deltas, and synchronizes clean records into Dataverse.

Stack: Python, Pandas, SharePoint REST API, Azure Key Vault, Dataverse, MS Graph

Business Outcome

  • Month-end processing reduced from 4 business days to 18 automated minutes.
  • Eliminated 100% of human copy-paste errors and discrepancy omissions.
  • Instant automated error-reporting notification dispatched to branch managers.

Enterprise BI & Financial KPI Dashboard System

Same-Day Executive Insights
